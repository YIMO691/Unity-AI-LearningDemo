# 学习路线

这份路线来自 `docs/manual.md`，被整理成可执行阶段。每阶段都先做一个可运行练习，再合并进最终 Demo。

## 阶段 0：环境与仓库基础（0.5-1 天）

- 创建 GitHub 远程仓库。
- 安装 Unity 6。
- 在 `UnityProject/` 创建 Unity 工程。
- 配置 Claude Code + DeepSeek。
- 建立基础场景、目录和第一个空测试。

验收：仓库已推送，Claude Code 可在 DeepSeek 后端下启动，Unity 工程可打开。

## 阶段 1：Unity 基础与传统 AI（约 2 周）

- 学习 Unity 编辑器、C# MonoBehaviour、组件生命周期。
- 实现敌人 FSM：巡逻、追踪、攻击、死亡。
- 使用 NavMeshAgent 完成导航。
- 用 Raycast/OverlapSphere 做基础感知。

练习：一个敌人可以在巡逻点间移动，发现玩家后追踪，进入范围后攻击。

## 阶段 2：行为树与群体 AI（约 2 周）

- 学习 Unity Behavior 或行为树思想。
- 把 FSM 原型迁移为行为树/行为图版本。
- 实现简单队形或群体协作。

练习：多名敌人能围绕玩家分工移动，避免全部挤在同一点。

## 阶段 3：ML-Agents 强化学习（约 3 周）

- 搭建 Python 环境和 ML-Agents 训练流程。
- 设计观察空间、动作空间和奖励。
- 用 TensorBoard 观察训练曲线。

练习：训练一个导航或射击靶子智能体，并记录奖励曲线。

## 阶段 4：Sentis/ONNX 推理集成（约 2 周）

- 导入 `.onnx` 模型。
- 编写推理输入输出映射。
- 记录 CPU/GPU 后端性能。

练习：把训练好的模型接入 Unity 运行时，或导入一个外部模型完成可见推理结果。

## 阶段 5：综合项目与交付（约 3 周）

- 整合传统 AI、群体 AI、ML 模型和推理。
- 增加测试、性能分析、演示录屏和说明文档。
- 配置 CI，并准备最终讲解材料。

验收：从 README 可复现项目，Demo 可运行，关键 AI 行为可解释。
