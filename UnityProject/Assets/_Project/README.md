# _Project Folder

This folder contains original Unity6_AI project content.

Planned structure:

- `Art/` for project-owned art assets.
- `Prefabs/` for reusable prefabs.
- `Scenes/` for project scenes.
- `Scripts/` for C# gameplay and AI code.
- `Tests/` for Unity Test Framework tests.

Do not place Unity cache, training outputs, API keys, or local settings here.
